# ❄️ 나만의 메모장

캘린더, 할 일(TO DO), 메모를 한 화면에서 쓰는 파스텔톤 메모장 웹페이지입니다.
눈 내리는 겨울 배경과 다크 모드를 지원하며, 파일 하나(`memo.html`)로 동작합니다.

> 국민대학교 AX-Startup 부트캠프 2기 실습으로 만들었습니다.

## 주요 기능

- **오늘 화면**: 오늘 일정, 오늘 마감인 할 일, 최근 메모를 한눈에
- **메모**: 쓰기·수정·삭제, 자동 저장, 검색, 중요 표시(★), 날짜 붙이기, 태그(공부/취업/개인), 텍스트 파일로 내보내기
- **할 일**: 추가·수정·삭제, 체크 표시, 마감일, 검색, 진행 중/완료 보기
- **캘린더**: 월간 달력, 날짜별 일정 추가·수정·삭제, 할 일 마감일과 날짜를 붙인 메모 표시
- **다크 모드**: 시작 화면과 메모장 어디서든 🌙/☀️ 버튼으로 전환
- **반응형**: 휴대폰처럼 좁은 화면에서도 보이도록 구성

## 사용하는 법

가장 쉬운 방법: `memo.html` 파일을 내려받아 더블클릭하면 브라우저에서 열립니다.

Windows에서 로컬 웹 서버로 열고 싶다면 `start-memo.ps1`을 실행하세요. (PowerShell 필요, 설치할 것 없음)

```powershell
powershell -ExecutionPolicy Bypass -File .\start-memo.ps1
```

브라우저에서 `http://localhost:5000` 주소로 열립니다. 서버를 끄려면 최소화된 PowerShell 창을 닫으면 됩니다.

## 데이터 저장 방식

메모, 할 일, 일정은 **내 브라우저 안(localStorage)에만** 저장됩니다.
서버로 전송되지 않으며, 다른 기기나 다른 브라우저와는 공유되지 않습니다.
브라우저의 사이트 데이터를 지우면 내용도 함께 지워지니, 중요한 메모는 "메모 내보내기"로 백업하세요.
(`localhost:5000`으로 열 때와 파일을 직접 열 때는 저장 공간이 서로 다릅니다.)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `memo.html` | 메모장 본체 (HTML, CSS, JavaScript가 모두 들어 있음) |
| `PRD.md` | 기획 문서 (무엇을, 누구를 위해, 어떤 순서로 만들지) |
| `serve.ps1` | 이 폴더를 `localhost`로 보여 주는 간단한 로컬 서버 (Windows 전용) |
| `start-memo.ps1` | 서버를 켜고 브라우저를 여는 시작 스크립트 (Windows 전용) |
